# Offline / Air-Gapped Deployment Guide

SOVEREIGN is designed to run in highly secure, air-gapped environments without internet access. This is critical for enterprise use cases where data sovereignty is paramount.

To successfully deploy SOVEREIGN completely offline, follow these steps while you still have internet access on a staging machine.

## 1. Pre-fetch Python Dependencies

On an internet-connected machine:
```bash
pip download -r requirements.txt -d ./offline_packages
```

Transfer the `offline_packages` folder to the air-gapped machine. Install them using:
```bash
pip install --no-index --find-links=./offline_packages -r requirements.txt
```

## 2. Pre-fetch Ollama Models

Ollama requires models to be downloaded before going offline.
Run the following commands on the staging machine:

```bash
ollama pull llama3
ollama pull qwen2.5-coder
ollama pull llava
```

Ollama models are typically stored in `~/.ollama` (Linux/Mac) or `C:\Users\<User>\.ollama` (Windows). You must copy this entire directory to the air-gapped machine.

Alternatively, if using Docker, export the Docker image or the volume containing the models.

## 3. Pre-fetch Embedding Models (Sentence Transformers)

The `sentence-transformers` library automatically downloads models from Hugging Face on the first run.
To pre-fetch the embedding model for offline use:

1. Write a simple Python script on the internet-connected machine:
   ```python
   from sentence_transformers import SentenceTransformer
   # This downloads the model to ~/.cache/huggingface/hub
   model = SentenceTransformer("all-MiniLM-L6-v2")
   ```
2. Run the script.
3. Copy the `~/.cache/huggingface/hub` directory to the same location on the air-gapped machine.

Alternatively, download the model files directly from Hugging Face and specify the local path when initializing the model in the code.

## 4. Install Tesseract OCR

Tesseract OCR is a system-level binary required for Vision processing.
Download the offline installer for Tesseract for your target OS (e.g., Windows `.exe`, or Debian `.deb` packages with all dependencies) and install it on the air-gapped machine.

Ensure Tesseract is added to the system `PATH`.

## 5. Security & Isolation Notes

- **No Cloud Fallbacks:** SOVEREIGN has been explicitly audited. There are no fallback calls to OpenAI, Azure, or Gemini.
- **Local Storage Restrictions:** All file writes generated by the AI occur inside the `local_outputs/` directory to prevent arbitrary file modifications.
- **RAG Datastore:** ChromaDB operates entirely locally and creates its SQLite database inside the workspace `chroma_db/`.
