# AI Integration Contract

This document defines the future interface boundary between the **Task Intelligence** module (owned by `friend`) and the **AI Execution Layer** (owned by `poovaragan`).

This is a conceptual design intended to guide Phase 1 development and ensure modular independence. The exact implementation details within the AI layer remain decoupled from the FastAPI backend.

## Input Payload (From Task Intelligence to AI Layer)

When the FastAPI application requests AI processing, it will construct and send a payload resembling this structure:

```json
{
  "task": "string",            // The primary instruction or user query
  "task_type": "string",       // e.g., "qa", "summarization", "extraction", "vision"
  "input_data": {},            // Additional structured parameters required for the task
  "files": [                   // Local paths or references to documents for this task
    {
      "file_path": "string",
      "file_type": "string"
    }
  ],
  "metadata": {                // Contextual data (e.g., user preferences, priority)
    "user_id": "string",
    "request_id": "string"
  }
}
```

## Output Payload (From AI Layer to Task Intelligence)

Once the AI Execution Layer (including Model Router, LangGraph, Ollama, Verification) has processed the request, it will return a payload resembling this structure:

```json
{
  "status": "string",          // e.g., "success", "failed", "requires_approval"
  "answer": "string",          // The generated text, response, or final output
  "model_used": "string",      // The local model that produced the answer (e.g., "llama3:8b")
  "sources": [                 // Information regarding documents used for RAG
    {
      "source_id": "string",
      "snippet": "string"
    }
  ],
  "files": [                   // Local paths or references to any artifacts generated by the AI
    {
      "file_path": "string",
      "description": "string"
    }
  ],
  "metadata": {                // Execution metadata (e.g., time taken, tokens used)
    "execution_time_ms": 1200,
    "tokens_generated": 256
  }
}
```

### Key Considerations
1. The AI layer remains internally independent. The FastAPI application does not need to know if the AI used RAG, multiple agents, or direct Ollama inference.
2. Sensitive tasks may result in a `"requires_approval"` status, at which point the frontend will prompt the user before execution proceeds.
